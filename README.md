# Harini — Personal Portfolio

A modern, responsive personal portfolio website built to showcase my web development skills, freelance services, and projects.

## 🌐 Live Website

https://harini-web-portfolio.vercel.app/

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern React-based UI
- Personal introduction and services
- Skills and technology showcase
- Featured project previews
- GitHub and LinkedIn integration
- Functional contact form with Formspree
- Production deployment with Vercel
- Smooth navigation and subtle animations

## 🛠️ Tech Stack

- React
- JavaScript
- HTML5
- CSS3
- Vite
- Formspree
- Git & GitHub
- Vercel
